# 同行日常

給自閉症（ASD）孩子照顧者的繁體中文育兒支持手冊。這份互動原型同時呈現桌面網站和手機 App 版面。

## 開啟原型

用瀏覽器開啟 [index.html](index.html) 即可試用。開啟「開始設定」會走完整首次流程，「看看示範首頁」會載入一組虛構偏好，「先逛資源」可直接瀏覽完整目錄。示範首頁的操作只保留在當次預覽。

也可以從 `mockup` 目錄啟動本機預覽。

```bash
python3 -m http.server 8768 --bind 127.0.0.1
```

## 與 Astra UIUX 確定的流程

| 畫面 | 家長能做什麼 |
| --- | --- |
| 首次設定 | 選填孩子的年齡區間與性別、勾選想優先了解的日常情境，再確認設定。任何欄位都可略過。 |
| 首頁 | 先看一篇重點推薦與推薦理由，再看其他主題。可以從首頁調整偏好。 |
| 資源目錄 | 瀏覽全部文章，輸入關鍵字或依分類篩選。找不到時能清除篩選。 |
| 文章 | 看適用情境、步驟、生活例子與調整方式。可以收藏、調整推薦，或在同一篇下新增及回看筆記。 |
| 收藏與設定 | 重看收藏、修改偏好，或在確認後清除這個瀏覽器的資料。 |

桌面採側欄，手機採底部導覽。第一版以 0–17 歲區間做示範。推薦先依家長選的情境排序，再以年齡命中排序。都略過時依預設順序提供入門文章。性別選填，推薦排序不使用性別。

偏好、收藏和筆記存於瀏覽器的 `localStorage`，不同瀏覽器、裝置或網址各自存放。每篇筆記依文章 ID 儲存，可以新增多則、編輯或刪除。示範模式的筆記保留在當次預覽。

## 內容收錄原則

所有公開文章都必須明確針對自閉症（ASD）孩子及其照顧者。來源本身或實際參考的章節必須明確討論 ASD，文章也必須說明對應的支持需求。一般育兒、一般身心障礙或廣義神經多樣性資料，不能只因可能對 ASD 有用就收錄。範圍無法確認時排除，僅保留稽核紀錄。

ASD適用性與改作授權分別查核。找不到適用於公開繁中整理／改寫的明確授權就不能用；私人列印、直連與原樣分享不當成改作權。逐筆決定記於[source-audit.json](source-audit.json)。產生資料時檢查來源核准範圍、適用授權、原文網址及複查結果，未通過者不能加入網站。這是編輯門檻，不代表自動驗證醫療效果。

資料時效依「可用、待複查、已過時」記錄。出版年份用於安排複查優先順序；判定過時須有新版取代、證據改變、資訊失效或現行指引修正等具體依據，並以實際引用的段落為單位。待複查的內容先不發布，判定理由與替代來源記在收集票。完整定義、記錄欄位與複查觸發條件見[來源盤點的時效規則](SOURCES.md#資料時效判定與複查)。

同題來源有差異時，保留各自作者、適用條件及證據限制，分辨是建議不同、情境不同，或仍不確定；不把差異抹平成單一結論，也不因意見不同直接淘汰來源。具體規則見[觀點差異的呈現原則](SOURCES.md#來源觀點有差異時的呈現)。

截至2026-11-21第二輪，共[66筆索引紀錄](RESEARCH-INDEX.md)：23筆可改寫指定範圍、3筆只限非商業、30筆本案不能用、10筆ASD範圍排除。[第一輪11筆](RESEARCH-2026-11-21.md)含7筆可用指定範圍與4筆排除；[第二輪11筆](RESEARCH-2026-11-21-02.md)含6筆可用指定範圍、2筆限非商業、2筆不用、1筆ASD範圍排除。來源紀錄不等於完成全文整合或已發布文章，網站仍為21篇。查不到的日期／數字年齡如實記為原文未標或未能核實，不編造資料，也不把沒有授權的來源繼續當候選。

[16個題目群](TOPIC-BRIEFS.md)已依結果更新，缺合格來源的題目明列缺口。原3C對照不再使用已排除材料作上架底稿；[複查結論](MEDIA-REVIEW.md)保留可用研究紀錄及限制。原17篇逐篇核對後保留，四篇感官文章改引授權清楚的S30。2026-11-20再把S05、S18、S19、S24的核准範圍整理成四篇試讀文章，目前共21篇、引用10筆來源。新文章在做法附近交代資料觀點與限制，原創提問及例子另行標示；S29限非商業資料未加入。

原來源未訂一致數字適齡。文章以「參考年齡」顯示本指南的情境分組並說明依據；只引學齡材料的文章已移除0–1／2–5歲標籤。個人筆記、收藏與固定文章ID維持。

2026-11-19 已追溯檢查原有 28 篇，先下架 11 篇一般性資料文章，保留 17 篇有 ASD 來源的試讀文章。下架文章的正文及來源不再進入公開目錄、推薦或資料來源頁。`withdrawnArticles` 只留固定 ID 與標題，舊網址顯示停收通知及使用者自己的本機筆記；收藏頁僅在有舊收藏或筆記時提供個人紀錄入口，不刪除原有筆記。

## 內容架構

目錄有七個單層分類，點分類就顯示文章。每篇依「家長讀完要處理什麼需求」選擇一個主分類。文章提及的裝置、採用的溝通技巧與適用對象可以用關鍵字、情境與性別標籤描述。

| 分類 | 收錄方向 | 目前篇數 |
| --- | --- | --- |
| 日常作息與轉換 | 出門、用餐、睡前與活動收尾 | 5 |
| 溝通與人際互動 | 表達需要、回應、拒絕與友誼支持 | 4 |
| 感官與環境 | 聲音、燈光、衣物觸感與情境記錄 | 4 |
| 情緒與壓力 | 陪伴情緒、察覺壓力與事後回顧 | 4 |
| 身體成長與界線 | 初經、變聲、身體自主 | 0 |
| 學校生活與親師合作 | 換班、閱讀理解、與老師討論支持 | 4 |
| 照顧者支持與找資源 | 照顧分工、評估與在地服務 | 0 |

首次設定和偏好編輯使用十個可複選的生活情境。每篇可以對應多個情境，例如〈讓下一步，看得見〉可由「收玩具或換活動」和「用餐」推薦。搜尋可比對內容、分類、情境和關鍵字。男、女標籤機制保留，之後有符合 ASD 收錄條件的相關文章再使用。暫無合格文章的分類不顯示於首頁與目錄篩選；七分類定義仍保留。

分類原案由 Astra 協作檢視當時 28 篇的歸屬，並參考專業機構如何區分發展、溝通、教育及服務支持。分類選擇為本專案的設計判斷，仍待家長試找驗證。[Raising Children Network 分類](https://raisingchildren.net.au/autism) · [National Autistic Society 分類](https://www.autism.org.uk/advice-and-guidance)

目前共有21篇附ASD出處的試讀文章。[來源盤點](SOURCES.md#現行文章逐篇查核)列出逐篇查核結果；可用判定僅限實際引用範圍。

[共用內容 JSON](catalog.json) 是文章、目錄分類、情境與來源的資料檔。文章使用固定 ID，供網站、App 和收藏引用。修改 JSON 後，在 `mockup` 目錄更新瀏覽器用的資料副本。

```bash
python3 build-content.py
python3 build-content.py --check
```

瀏覽器副本能讓本機 HTML 直接讀取資料。
