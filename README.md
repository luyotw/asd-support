# 同行日常

給自閉症（ASD）孩子照顧者的繁體中文育兒支持手冊。這份互動原型同時呈現桌面網站和手機 App 版面。

## 開啟原型

用瀏覽器開啟 [index.html](index.html) 即可試用。開啟「開始設定」會走完整首次流程，「看看示範首頁」會載入一組虛構偏好，「先逛資源」可直接瀏覽完整目錄。示範首頁的操作只保留在當次預覽。

也可以從 `mockup` 目錄啟動本機預覽。

```bash
python3 -m http.server 8768 --bind 127.0.0.1
```

## 與 Astra UIUX 確定的流程

| 畫面 | 家長能做什麼 |
| --- | --- |
| 首次設定 | 選填孩子的年齡區間與性別、勾選想優先了解的日常情境，再確認設定。任何欄位都可略過。 |
| 首頁 | 先看一篇重點推薦與推薦理由，再看其他主題。可以從首頁調整偏好。 |
| 資源目錄 | 瀏覽全部文章，輸入關鍵字或依分類篩選。找不到時能清除篩選。 |
| 文章 | 看適用情境、步驟、生活例子與調整方式。可以收藏、調整推薦，或在同一篇下新增及回看筆記。 |
| 收藏與設定 | 重看收藏、修改偏好，或在確認後清除這個瀏覽器的資料。 |

桌面採側欄，手機採底部導覽。第一版以 0–17 歲區間做示範。推薦先依家長選的情境排序，再以年齡命中排序。都略過時依預設順序提供入門文章。性別選填，推薦排序不使用性別。

偏好、收藏和筆記存於瀏覽器的 `localStorage`，不同瀏覽器、裝置或網址各自存放。每篇筆記依文章 ID 儲存，可以新增多則、編輯或刪除。示範模式的筆記保留在當次預覽。

## 內容架構

目錄有六個分類，點分類就顯示文章。首次設定和偏好編輯使用十個可複選的生活情境。每篇文章歸在一個分類，並可以有多個情境標籤。例如〈讓下一步，看得見〉歸在「日常生活與活動轉換」，可由「收玩具或換活動」和「用餐」推薦。搜尋可比對文章內容、分類與情境。

目前共有 21 篇，包含 18 篇附出處的試讀文章和 3 篇台灣官方資源導引。出處、實際參考範圍與授權記在[來源盤點](SOURCES.md)。

[共用內容 JSON](catalog.json) 是文章、目錄分類、情境與來源的資料檔。文章使用固定 ID，供網站、App 和收藏引用。修改 JSON 後，在 `mockup` 目錄更新瀏覽器用的資料副本。

```bash
python3 build-content.py
python3 build-content.py --check
```

瀏覽器副本能讓本機 HTML 直接讀取資料。

## 插畫

[原型插畫](assets/together.webp)以內建 ImageGen 生成。生成提示為暖米色與墨綠的台灣兒童繪本剪紙／水粉風格，描繪一位家長陪孩子坐在居家地毯上看圖卡，孩子主動指向自己的選擇。插畫無文字與標誌，以橫幅裁切可保留親子互動。
