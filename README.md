# 星泊

給自閉症（ASD）孩子照顧者的繁體中文育兒支持手冊。這份互動原型同時呈現桌面網站和手機 App 版面。

## 開啟原型

用瀏覽器開啟 [index.html](index.html) 即可試用。可以從「開始設定」建立偏好，也可以直接開啟「育兒指南」或「查資源」。

也可以從 `mockup` 目錄啟動本機預覽。

```bash
python3 -m http.server 8768 --bind 127.0.0.1
```

## 與 Astra UIUX 確定的流程

| 畫面 | 家長能做什麼 |
| --- | --- |
| 首次設定 | 選填孩子的年齡與性別，勾選生活情境與想查的資源。任何欄位都可略過。 |
| 首頁 | 以「下一則」輪看育兒指南與符合需求的資源。相關資源區另列最多兩篇。 |
| 育兒指南 | 按生活情境分類瀏覽或搜尋 41 篇指南。 |
| 資源專區 | 依評估與申請、補助與生活優惠、領證與投保查閱 8 篇資源。各篇開頭顯示適用對象、窗口、官方連結與查核日。愛心卡可跳到指定縣市。 |
| 全站搜尋 | 點頁首的搜尋，同時查找育兒指南和資源。 |
| 文章 | 從摘要和來源開始，閱讀各篇小標下的做法、例子和來源差異。文末有相關文章、筆記、收藏與推薦設定。 |
| 收藏與設定 | 重看收藏、修改偏好，或在確認後清除這個瀏覽器的資料。 |

桌面採側欄，手機採底部導覽。年齡區間涵蓋 0–17 歲。首頁依情境與年齡將育兒指南排出優先順序，並在同一優先順序內洗牌。符合勾選需求與年齡的資源也會洗牌，和指南交錯顯示。同一輪的主推薦依序看完後再洗牌。

偏好、收藏和筆記存於瀏覽器的 `localStorage`，不同瀏覽器、裝置或網址各自存放。每篇筆記依文章 ID 儲存，可以新增多則、編輯或刪除。

## 內容收錄原則

所有公開文章都必須明確針對自閉症（ASD）孩子及其照顧者。來源本身或實際參考的章節必須明確討論 ASD，文章也必須說明對應的支持需求。一般育兒、一般身心障礙或廣義神經多樣性資料，不能只因可能對 ASD 有用就收錄。範圍無法確認時排除，僅保留稽核紀錄。

ASD 適用性與使用方式分別查核。翻譯、重製或改寫原文依適用授權。若只使用原文提出的觀點、研究事實或案例經過，可用獨立表述加作者及原文連結，保留適用範圍與限制。逐筆決定記於[來源稽核](source-audit.json)。[署名概述與原文連結](SOURCES.md#署名概述與原文連結)

星泊免費提供非商業內容。明確允許非商業改作的來源可按個別條款收錄，發布時保留授權連結、署名及改寫標記。若日後開放自由贊助，會與內容存取分開，規則見[非商業授權與自由贊助](SOURCES.md#非商業授權與自由贊助)。

資料時效依「可用、待複查、已過時」記錄。出版年份用於安排複查優先順序；判定過時須有新版取代、證據改變、資訊失效或現行指引修正等具體依據，並以實際引用的段落為單位。待複查的內容先不發布，判定理由與替代來源記在收集票。完整定義、記錄欄位與複查觸發條件見[來源盤點的時效規則](SOURCES.md#資料時效判定與複查)。

星泊收集、查核與整理資料。文章的觀點與建議須標明來源，家長可依需要比較。

同題來源有差異時，保留各自作者、適用條件及證據限制，分辨是建議不同、情境不同，或仍不確定；不把差異抹平成單一結論，也不因意見不同直接淘汰來源。具體規則見[觀點差異的呈現原則](SOURCES.md#來源觀點有差異時的呈現)。

截至 2026-11-26，共[139 筆索引紀錄](RESEARCH-INDEX.md)，其中 44 筆可改寫指定範圍、12 筆可非商業改寫指定範圍、33 筆可署名概述並連回原文、38 筆本案不能用、12 筆 ASD 範圍排除。[第一輪11筆](RESEARCH-2026-11-21.md)含7筆可用指定範圍與4筆排除；[第二輪11筆](RESEARCH-2026-11-21-02.md)含6筆可用指定範圍、2筆限非商業、2筆不用、1筆ASD範圍排除。來源索引記錄各筆資料可引用的範圍。查不到的日期／數字年齡如實記為原文未標或未能核實，不編造資料。

[34個題目群](TOPIC-BRIEFS.md)已依結果更新，缺合格來源的題目明列缺口。原3C對照不再使用已排除材料作上架底稿；[複查結論](MEDIA-REVIEW.md)保留可用研究紀錄及限制。原17篇逐篇核對後保留，四篇感官文章改引授權清楚的S30。2026-11-20再把S05、S18、S19、S24的核准範圍整理成四篇試讀文章。2026-11-21再整理9篇，涵蓋談診斷、親友分工、家長團體、如廁求助、男孩青春期、初經、身體界線、螢幕收尾與上學困難。2026-11-24新增七篇早療指南，涵蓋評估、報告、補助、居家溝通、AAC、學前特教與升小一轉銜。同日針對特教鑑定、身心障礙證明、投保及校園隱私新增十一篇，並為22篇既有文章補進新查核的 ASD 資料。2026-11-25 補查身障福利並新增全臺 22 縣市愛心卡額度。同日[逐題補查 30 篇指南的臺灣來源](RESEARCH-2026-11-25-TAIWAN.md)，18 篇補上在地資料。2026-11-26 [全站重查](RESEARCH-2026-11-26-ATTRIBUTED-SOURCES.md)後，現有 49 篇共引用 89 筆來源。多來源文章在做法附近並列觀點與限制，原創提問與例子另行標示。

原來源未訂一致數字適齡。文章以「參考年齡」顯示本指南的情境分組並說明依據；只引學齡材料的文章已移除0–1／2–5歲標籤。個人筆記、收藏與固定文章ID維持。

2026-11-19 已追溯檢查原有 28 篇，先下架 11 篇一般性資料文章，保留 17 篇有 ASD 來源的試讀文章。下架文章的正文及來源不再進入公開目錄、推薦或資料來源頁。`withdrawnArticles` 只留固定 ID 與標題，仍暫停的題目會由原網址顯示通知與本機筆記。獲得 ASD 來源後重寫的四篇沿用原網址，方便取回同題筆記和收藏。

## 內容架構

目錄有七個單層分類，點分類就顯示文章。每篇依「家長讀完要處理什麼需求」選擇一個主分類。文章提及的裝置、採用的溝通技巧與適用對象可以用關鍵字、情境與性別標籤描述。

| 分類 | 收錄方向 | 目前篇數 |
| --- | --- | --- |
| 日常作息與轉換 | 出門、用餐、睡前與活動收尾 | 7 |
| 溝通與人際互動 | 表達需要、回應、拒絕與友誼支持 | 6 |
| 感官與環境 | 聲音、燈光、衣物觸感與情境記錄 | 4 |
| 情緒與壓力 | 陪伴情緒、察覺壓力與事後回顧 | 4 |
| 身體成長與界線 | 初經、青春期變化、身體自主 | 3 |
| 學校生活與親師合作 | 換班、閱讀理解、與老師討論支持 | 12 |
| 照顧者支持 | 照顧分工、家長支持與早療對話 | 5 |

首次設定和偏好編輯提供可複選的生活情境與資源需求。每篇可以對應多個情境，例如〈讓下一步，看得見〉可由「收玩具或換活動」和「用餐」推薦。搜尋可比對內容、分類、情境和關鍵字。男孩青春期與初經文章分別標上「男」與「女」。搜尋可用標籤找到文章，適用情境請一起看實際身體變化與需求。

分類原案由 Astra 協作檢視當時 28 篇的歸屬，並參考專業機構如何區分發展、溝通、教育及服務支持。分類選擇為本專案的設計判斷，仍待家長試找驗證。[Raising Children Network 分類](https://raisingchildren.net.au/autism) · [National Autistic Society 分類](https://www.autism.org.uk/advice-and-guidance)

目前共有49篇附ASD出處的試讀文章。[來源盤點](SOURCES.md#現行文章逐篇查核)列出逐篇查核結果；可用判定僅限實際引用範圍。

[共用內容 JSON](catalog.json) 是文章、目錄分類、情境與來源的資料檔。文章使用固定 ID，供網站、App 和收藏引用。含有 `resource` 欄位的文章顯示在資源專區，欄位指定分類、推薦需求、適用對象、窗口和官方連結。各篇內文依 `sections` 的順序呈現。每段含小標 `heading`，正文可用 `paragraphs` 或 `list.items`，也可並用。設定 `list.ordered` 為 `true` 會顯示編號。可在同段加入 `evidence` 交代來源差異及限制。 以 `sourceNotes` 刊載已核准的署名概述及原文連結。文章末尾用 `relatedArticles` 連到其他已發布文章。來源區預先顯示前兩筆，完整引用、署名與參考年齡的依據可展開查看。修改 JSON 後，在 `mockup` 目錄更新瀏覽器用的資料副本。

```bash
python3 build-content.py
python3 build-content.py --check
```

瀏覽器副本能讓本機 HTML 直接讀取資料。
